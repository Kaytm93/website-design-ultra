## Role rules

- Give display, body, and mono distinct jobs; do not add a family without a job.
- Prefer one variable family with optical sizing when it can create enough contrast by itself.
- Use tabular figures for aligned data. Monospace is optional unless the direction or content calls for it.
- Test numerals, currency, punctuation, fractions, arrows, and status symbols in data-heavy products.
- Do not use a display cut for long body copy merely to preserve a pairing.
- Avoid synthetic bold/italic. Load or generate only real styles covered by the license.

## Pairing check

1. Render hero, body paragraph, navigation, button, table row, and error message.
2. Compare x-height, punctuation color, numeral width, and bold contrast.
3. Test each supported script rather than assuming the Latin pairing extends.
4. Remove the second family if hierarchy remains clear without it.
