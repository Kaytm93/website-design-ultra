# Expressive Palettes

Use one palette. Supporting colors are decorative unless a semantic role is explicitly assigned.

## 1. Cyber Cockpit

```yaml
bg: "#000814"
surface: "#001d3d"
border: "#7ea2c8"
text: "#ffffff"
muted: "#7ea2c8"
action: "#ffc300"
on-action: "#000814"
focus: "#ffc300"
danger: "#ff8a80"
on-danger: "#000000"
disabled: "#7ea2c8"
```

Use: aerospace, technical gaming, dense dark interfaces.
