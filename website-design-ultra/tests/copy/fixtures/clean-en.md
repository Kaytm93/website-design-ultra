# Turn a recorded call into a Markdown file with owners and due dates

Every call is transcribed in German or English. The export writes one Markdown
file per meeting, with each action item attached to the person who accepted it
and the date they named.

Transcription runs on the recording you upload; nothing is captured live. Two
languages are supported today. If a speaker switches mid-sentence, the
transcript keeps the switch and marks it.
