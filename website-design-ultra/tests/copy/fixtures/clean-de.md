# Aus einer Aufnahme wird eine Markdown-Datei mit Zuständigkeiten und Fristen

Jeder Anruf wird auf Deutsch oder Englisch transkribiert. Der Export schreibt
pro Meeting eine Datei. Jede Aufgabe steht dort unter dem Namen der Person, die
sie übernommen hat, samt dem Datum, das sie genannt hat.

Die Transkription läuft über die Aufnahme, die Sie hochladen; live wird nichts
mitgeschnitten. Zwei Sprachen sind heute unterstützt. Wechselt eine Person
mitten im Satz die Sprache, bleibt der Wechsel im Text stehen und wird markiert.
